CLOUD SECURITY COURSE

Cloud Security

Learn how to protect cloud resources using identity management, authentication, permissions, monitoring and security best practices.

⏱ 6 Weeks 📈 Intermediate 🎓 Practical Learning

🔐 IAM

Learn users, groups, roles, permissions and the principle of least privilege.

🛡️ MFA

Understand multi-factor authentication and how it adds an additional security layer to accounts.

📜 Policies

Learn how IAM policies control access to AWS resources using permissions.

🪣 S3 Security

Understand bucket permissions, access control and safe handling of cloud-stored data.

📊 CloudTrail

Learn how AWS API activity can be recorded for auditing and security investigation.

🔎 Security Practices

Learn secure credentials, least privilege, monitoring and regular access review practices.
